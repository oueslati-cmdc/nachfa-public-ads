# NACHFA — Publicité vidéo officielle

Ce dépôt public contient uniquement les supports publicitaires finaux destinés à Meta Ads. Le projet Remotion, les rushs et les pistes vocales séparées restent privés.

## Vidéo Meta Ads

Téléverser le fichier final sous le nom exact `nachfa-meta-ad.mp4` à la racine du dépôt via **Add file → Upload files**.

Une fois le fichier ajouté, son URL directe sera :

https://raw.githubusercontent.com/oueslati-cmdc/nachfa-public-ads/main/nachfa-meta-ad.mp4

Ne pas utiliser cette URL tant que le fichier n'est pas présent et accessible publiquement.

## Campagne

- Marque : NACHFA
- Format : vertical 1080 × 1920
- Durée : 24 secondes
- Landing page : https://nachfa.converty.shop/
- Publicité : désactivée avant vérification et autorisation explicite de diffusion
